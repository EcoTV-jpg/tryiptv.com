# AI Search / GEO / Answer Engine Readiness

Treat AI-search optimization as information quality + entity clarity + extractability + evidence. Do not promise inclusion.

## Review
- concise answer-first passages
- clear entity naming
- stable facts
- source/evidence links
- original observations/tests
- tables/comparisons when genuinely useful
- descriptive headings
- self-contained explanations
- contradiction-free claims
- update dates only when real
- author/reviewer context when meaningful

## AI Overviews / answer engines
Prioritize pages that:
- directly answer the query
- expose useful factual units
- differentiate from generic summaries
- contain verifiable evidence
- have strong site architecture and crawlability

## Files and myths
Treat these cautiously:
- `llms.txt`
- `llms-full.txt`
- `ai.txt`

They may be useful for tooling/ecosystem experiments but must not be presented as proven Google ranking factors.

## No synthetic authority
Never fabricate:
- citations
- expert endorsements
- customer numbers
- tests not performed
- benchmark data
