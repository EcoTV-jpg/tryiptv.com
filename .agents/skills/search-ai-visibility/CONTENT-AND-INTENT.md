# Content, Intent, Cannibalization, Helpful Content

## Page purpose
For every indexable URL answer:
1. Who is it for?
2. What query/problem stage does it solve?
3. What is the primary intent?
4. What unique value exists here?
5. What should the user do next?
6. Why should this URL exist separately?

Mandatory question:
**What is the one thing this page will solve better than any URL that already exists?**

If there is no clear answer, flag overlap risk before recommending a new URL.

## Intent classes
Use practical categories, not rigid labels:
- learn/definition
- comparison
- troubleshooting
- setup/how-to
- commercial investigation
- pricing/transactional
- trial/demo
- navigational/entity

## Cannibalization
Do not flag merely because two pages share keywords.

Look for:
- same primary task
- same query set
- interchangeable content
- same SERP archetype
- unstable ranking URL in GSC
- internal anchors sending conflicting signals
- title/H1 differentiation without real content differentiation

Possible resolutions:
- merge
- reposition intent
- consolidate sections
- internal-link hierarchy
- redirect only when replacement is truly equivalent
- noindex only when page should not be searchable

## Content quality
Evaluate:
- answer-first usefulness
- factual accuracy
- specificity
- original evidence/experience
- screenshots/tests where useful
- contradiction removal
- claim support
- unnecessary repetition
- reader progression
- objections answered
- maintenance/freshness needs

## Prohibited recommendations
- arbitrary word counts
- keyword density targets
- AI-text detection scores as quality proof
- fake personal experience
- programmatic doorway pages
