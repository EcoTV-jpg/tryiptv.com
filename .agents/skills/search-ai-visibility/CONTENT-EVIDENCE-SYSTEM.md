# Content Evidence System

The strongest modern SEO content has evidence, not just prose.

## Evidence types
- first-hand screenshots
- original photos
- test methodology
- measured results
- product/service observations
- examples
- original tables
- changelogs
- primary-source citations
- expert review
- comparison methodology

## Evidence ledger
For high-value pages create:
- claim
- evidence source
- evidence date
- owner
- refresh trigger

## Claim classes
### Stable
Definitions, standards, protocol facts.

### Volatile
Prices, counts, compatibility, policies, availability, software versions.

### Comparative
“best”, “fastest”, “more reliable”, “cheaper”.

Comparative claims need methodology or should be rewritten as brand positioning/opinion.

## Update rule
Refresh because facts changed, not to manipulate dates.
