# Search Console and Measurement

## When GSC is available
Analyze by query + page, not averages alone.

Review:
- clicks
- impressions
- CTR
- average position
- date comparison
- country/device
- page/query pairs
- sitemap status
- indexing reports
- CWV
- manual actions/security if relevant

## Cannibalization evidence
Look for:
- same query switching among multiple URLs
- two URLs splitting impressions for the same intent
- ranking volatility after new overlapping content

Do not call brand/nonbrand variation cannibalization without intent overlap.

## Opportunity types
- high impressions, weak CTR → snippet/value proposition review
- positions 4–15 + strong intent fit → content/internal links/evidence
- declining clicks with stable position → SERP/CTR/demand changes
- falling impressions + position → relevance/competition/indexing investigation

## Analytics
Use for:
- landing-page engagement
- conversion
- device issues
- organic paths

Do not use engagement metrics as direct Google ranking-factor proof.

## Missing data
If historical or property access is unavailable, mark hypotheses `needs_validation`.
