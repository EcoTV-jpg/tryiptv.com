# SEO Experiment Framework

Use experiments for questions that official docs do not resolve.

## Hypothesis template
- change:
- expected mechanism:
- primary metric:
- secondary metric:
- cohort:
- control:
- start date:
- stop condition:
- confounders:

## Good experiments
- internal-link module on a page family
- improved answer-first section
- original comparison table + evidence
- title/snippet value proposition
- media enhancement
- consolidation of overlapping pages

## Bad experiments
- thousands of doorway pages
- hidden text
- fake review markup
- mass exact-match anchors
- cloaking
- changing several site-wide systems at once

## Interpretation
Do not call correlation causation.
Do not promote one site's result into a universal ranking factor.
