# Structured Data

## Rules
Structured data must:
- match visible content
- describe the actual page/entity
- use stable IDs
- avoid contradictory duplicates
- follow Google eligibility when rich-result intent is claimed

## Inspect
- Organization
- WebSite
- BreadcrumbList
- Article/BlogPosting
- Product/Offer
- Service
- FAQPage
- HowTo
- VideoObject
- LocalBusiness where applicable

## Validate
For each graph:
- page-type fit
- required/recommended properties
- visible evidence
- price/currency/availability consistency
- URL/entity IDs
- logo/image validity
- duplicate nodes

## High-risk anti-patterns
Reject:
- review stars with no genuine qualifying review data
- Product schema on generic service pages merely to chase stars
- FAQ markup where FAQ rich results are not applicable/eligible
- fake ratings
- invisible structured-data-only claims
- schema copied globally to unrelated pages

## Reporting
Classify:
- invalid
- misleading
- ineligible
- redundant
- enhancement opportunity

Do not call an enhancement opportunity a ranking problem.
