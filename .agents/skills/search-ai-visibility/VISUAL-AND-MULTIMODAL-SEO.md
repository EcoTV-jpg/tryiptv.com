# Visual and Multimodal SEO

Search is increasingly multimodal.

## Images
Review:
- original/useful imagery
- descriptive context
- correct dimensions
- responsive delivery
- crawlable image URLs
- meaningful alt text
- filenames only where useful
- image sitemap where applicable
- no text-only facts trapped inside images

## Video
Review:
- page relevance
- visible video
- descriptive title/context
- thumbnail accessibility
- video structured data when eligible
- transcript/key facts where helpful

## Google multimodal reporting
Where Search Console exposes multimodal search data, use it to identify:
- pages surfaced through image-led searches
- image/video content with visibility
- device/query differences

## AI use
Do not add images merely because “AI likes visuals.”
Use them when they add evidence, demonstrate experience, explain steps, show comparisons, or support product/entity understanding.
